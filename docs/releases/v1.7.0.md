## MCP 服务器网页访问

- 新增 `browser_open`、`browser_list`、`browser_close`，可通过 MCP 创建、重新获取和关闭服务器网页访问链接。
- 在连接编辑窗口勾选“允许 MCP 看到此配置”和“允许获取网页访问链接”，再用 `profiles_list` 获取连接 ID。
- 调用 `browser_open`，例如 `{"profile_id":"连接ID","target_url":"http://127.0.0.1:8080"}`；目标中的 `127.0.0.1` 指远端 SSH 服务器。
- 返回的完整 `access_url` 可在 LabRemote 所在电脑的任意浏览器打开。保持 LabRemote 和连接运行，保留完整令牌路径；链接不能在其他电脑使用，也不应公开发布。目标端口无需开放公网，但 SSH 服务端必须允许 TCP 转发。

## 补齐现有能力

- 新增 `file_list_directory`，通过 SFTP 浏览远端目录，返回名称、路径、目录和符号链接标记、大小及修改时间；需要文件上传或下载权限之一。
- 新增 `ssh_session_directory`，查询 MCP 终端当前工作目录；远端需支持 `/proc`，不支持时明确返回错误。
- MCP 工具总数从 16 个增加到 21 个，连接列表补齐权限标记，连接状态增加网页代理数量；权限界面及静态、自动导出的 AI 手册同步更新。
- 修正 Windows 上 SoftEther 取消测试的定时器调度竞争，保留取消与超时校验。

## 权限与生命周期

- 新增独立网页访问权限 `allow_browser`，旧配置默认关闭。升级后需手动授权并重新加载 MCP 客户端以发现新工具。
- MCP 与桌面网页代理相互隔离，相同目标复用 MCP 自有代理，每个 Profile 最多 16 个 MCP 代理。
- 停止 MCP、重新生成令牌、主动断开或撤销网页权限会回收相应 MCP 代理；停止 MCP 保留桌面代理。
- 桌面终端或网页代理正在使用连接时，即使 `force=true`，MCP 也不能断开该连接。审计不记录网页目标、访问链接或令牌。
