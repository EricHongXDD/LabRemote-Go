## aTrust 会话保持与认证窗口

- 将本应用取得的 aTrust 登录票据和固定设备标识保存在系统凭据库，测试、保存后的正式连接和重启应用可以恢复有效会话；不保存密码、验证码或其他客户端的登录资料，票据不随连接配置导出。
- 点击认证或测试 SSH 后，需要登录时自动打开独立 Edge/Chrome 窗口；改进窗口前置，并区分浏览器启动失败、主动取消和等待超时。
- 保存配置时接续测试取得的认证，避免保存后再次登录；新增“清除 aTrust 登录状态”入口，更换网关或删除配置时清理对应票据。

## MCP 连接稳定性

- 修复将 Passport 网页会话失效误判为 aTrust 数据票据失效的问题。恢复时以 SDP 授权资源为准，每条目标数据连接继续由网关认证并匹配资源权限，不再重入首次登录接口。
- 新建 SFTP 下载或上传通道时，不再因网页会话过期而关闭活动 SSH；网络故障、资源权限拒绝和其他网关业务故障会保留票据供重试。
- 并发 MCP 健康检查复用同一次 SSH 保活，取消或超时的单个等待请求不再误关其他请求共享的 SSH；连接自身保活超时仍会淘汰失效客户端。

## 验证与兼容性

- 通过 Go 全量测试、静态检查、前端测试与生产构建，以及 Windows 系统凭据库读写测试。
- 真实网关已实测：复用已有票据恢复新客户端、重复查询授权资源并建立新的 SSH 数据通道，全程无需重新网页登录。
- 按 MCP 服务路径完成三轮命令和只读文件下载，覆盖原先的 30 秒会话检查周期，未重新认证或关闭共享 SSH。该结果不代表所有网络或网关策略下都不会断开。
- aTrust 仍为实验性适配，独立网页登录支持 Windows/Linux 上的 Edge/Chrome；服务端真正撤销数据授权、票据过期或要求重新认证时，仍需按提示完成验证。
- Windows 提供便携程序与安装包，Linux 提供 amd64 压缩包，macOS 提供通用应用；校验值与第三方许可分别见 `SHA256SUMS.txt`、`LabRemote-third-party-licenses.zip`。
