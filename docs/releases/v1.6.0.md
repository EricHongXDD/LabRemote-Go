## 新增

- OpenVPN 进程内隔离隧道：导入 `.ovpn` / ZIP，支持账号密码和 OTP/TOTP 弹窗，无需安装或调用本机 OpenVPN 客户端。
- aTrust 实验性进程内 TCP 接入：填写 HTTPS 服务器地址，在独立 Edge/Chrome 窗口手动完成网页登录，仅连接配置中的 SSH 目标，不启动 aTrust 客户端或配置系统 VPN。
- 同一编辑窗口复用已认证的 OpenVPN/aTrust 测试会话，修改 SSH 参数或测试失败后无需逐次重新认证；关闭窗口、更改 VPN 入口或空闲 15 分钟后回收。

## 优化与修复

- 用圆角自定义下拉框统一连接方式和认证方式选择，移除服务提供方专属界面文案。
- 改进 OpenVPN 非对称 V1/V2 数据格式、LZO 和目标连通性诊断。
- 区分 SSH 握手超时、对端关闭和真实身份认证失败；继续保留证书和 SSH 主机指纹验证。
- 增加协议回归测试及发行包第三方许可证、源码和重新构建说明。

## 兼容性说明

- aTrust 当前为实验性适配，独立网页登录窗口支持 Windows/Linux 上已安装的 Edge/Chrome；不支持的认证方式、额外终端准入或资源策略会明确失败，不回退到系统直连。
- aTrust 网页认证和授权资源匹配已实测通过；真实 SSH 目标的连通性仍取决于部署和目标服务，本版本不宣称已修复服务器端拒绝或关闭连接的问题。
- OTP/TOTP 本身不会保存或永久复用；仅在有效会话内复用认证状态。
- Windows 提供便携程序和安装包，Linux 提供 amd64 压缩包，macOS 提供通用应用；校验值见 `SHA256SUMS.txt`，许可和重新构建说明见 `LabRemote-third-party-licenses.zip`。
