## aTrust 过期认证恢复

- 修复网关通过 HTTP 403 返回明确会话失效业务码时，应用误报“会话复核暂时失败，请检查网络”并始终无法重新登录的问题。
- HTTP 非成功响应现在保留并脱敏解析网关业务码，支持数字和字符串形式；确认票据过期后自动进入一次重新认证。
- 普通权限拒绝、未知 403 和临时业务故障仍保留票据，提示安全的 HTTP 状态码及业务码，避免无谓重复登录；完整响应正文、票据等敏感内容不进入错误提示。

## 独立认证窗口

- 浏览器启动器正常退出后继续等待本次临时配置的独立窗口就绪，不再立即误报“认证窗口已关闭”。
- 保留实际启动失败的退出码，区分启动失败、窗口未就绪、超时和主动取消。

## 验证与使用说明

- 通过 Go 全量测试、静态检查及相关回归测试；真实过期票据已验证会正确转入认证，诊断过程未改动系统中的票据。
- 本机浏览器回调测试及桌面模式测试通过；修复版已实际打开并保持独立 Edge 统一认证页面。最终账号登录和验证码步骤仍需用户手动完成，本次未完成最终登录实测。
- aTrust 仍为实验性进程内目标 TCP 通道，不调用本机 VPN 客户端，不修改系统路由或代理。服务端要求重新认证时仍需完成验证。
- Windows 提供便携程序和安装包，Linux 提供 amd64 压缩包，macOS 提供通用应用；校验值与许可分别见 `SHA256SUMS.txt`、`LabRemote-third-party-licenses.zip`。
